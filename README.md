# 🐦 X Post Generator v5

Веб-редактор для создания реалистичных мокапов постов X (Twitter): лента, уведомления, сообщения, диалоги. Всё в одном HTML-файле, без бэкенда.

![Скриншот](docs/screenshots/preview.png)

## ✨ Возможности

- 🎨 **Тёмная тема** редактора и превью телефона
- 👤 **Персонажи** — создай один раз, используй везде
- 📱 **Экраны** разных типов:
  - Лента твитов
  - Уведомления
  - Сообщения (список диалогов)
  - Открытый диалог / групповой чат
  - Заголовок в шапке
- 🔔 **Баннеры-уведомления** сверху экрана
- 🧵 **Треды** с линиями связей между постами
- 💾 **Автосохранение** в браузере (LocalStorage)
- 📤 **Экспорт в PNG**: один экран / все экраны / коллаж
- 🔄 **Синхронизация через GitHub Gist** — перенос между устройствами
- 🌐 **Работает офлайн** — никаких серверов

## 🚀 Быстрый старт

### Вариант 1: Просто открыть файл
```bash
# Скачай index.html и открой в браузере
open index.html
```

### Вариант 2: Локальный сервер (рекомендуется)
```bash
# Через Python
python -m http.server 8000

# Через Node.js
npx serve

# Через PHP
php -S localhost:8000
```
Открой http://localhost:8000

### Вариант 3: GitHub Pages
Форкни репозиторий → Settings → Pages → Deploy from `main` branch → готово.

## 🎮 Использование

1. **Персонажи** → создай аватары с никами, описаниями, локациями
2. **Экраны** → добавь экран нужного типа (лента / диалог / уведомления)
3. **Посты / Сообщения** → наполняй контент, применяй персонажей в один клик
4. **Экспорт PNG** → скачай результат или коллаж всех экранов

### Синхронизация между устройствами
1. Создай [Personal Access Token](https://github.com/settings/tokens) со scope `gist`
2. Создай пустой Gist (или укажи ID существующего)
3. Введи токен и Gist ID в настройках → «Сохранить настройки»
4. Используй «Отправить в облако» / «Загрузить из облака»

> 🔒 Токен и Gist ID хранятся **только в твоём браузере** (LocalStorage). Данные уходят исключительно на `api.github.com`.

## 🛠 Технологии

- **Чистый HTML/CSS/JS** — без фреймворков
- **html2canvas** — рендер в PNG
- **GitHub Gist API** — облачная синхронизация
- **LocalStorage** — локальное хранение
